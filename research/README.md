# Research

Este directorio contiene investigaciones sobre el producto, mercado, regulación, tecnología y operaciones de ArcPOS.

## Cómo usarlo

Cada investigación debe separar claramente:

- **Hechos:** información respaldada por fuentes.
- **Supuestos:** hipótesis todavía no validadas.
- **Conclusiones:** decisiones o aprendizajes derivados.
- **Acciones:** qué debemos investigar, probar o decidir después.

No se deben tratar las conclusiones como requisitos definitivos si dependen de una fuente comercial, regulación cambiante o validación con proveedores.

## Convención de nombres

```text
NNN-tema-corto.md
```

Ejemplos:

- `001-pagos-qr-argentina.md`
- `002-circle-arc-y-usdc.md`
- `003-tap-to-pay-iphone.md`
- `004-entrevistas-comercios.md`

## Estado

Usar uno de estos estados en cada informe:

- `exploratory`: investigación inicial.
- `in-progress`: faltan fuentes o validaciones.
- `validated`: confirmado con fuentes y/o pruebas.
- `decision`: convertido en una decisión de producto.
- `superseded`: reemplazado por una investigación posterior.
